# -AI-Based-Personal-Study-Planner
Project Report 
AI-Based Personal Study Planner 
Introduction 
The AI-Based Personal Study Planner is a simple Python 
application designed to help students organize their study time 
effectively. The program collects information about subjects, 
their difficulty levels, and the number of days left until exams. 
Based on this information, it generates a personalized study 
schedule. 
The project demonstrates how basic AI concepts can be used 
to support decision-making and provide useful 
recommendations to users. 
Objectives 
• To develop a study planning system using Python. 
• To apply Object-Oriented Programming (OOP) concepts. 
• To use an AI-inspired approach for prioritizing subjects. 
• To help students manage their study time efficiently. 
Working of the Project 
The user enters the details of each subject, including its 
difficulty level and the days remaining before the exam. The 
system then calculates a priority score for each subject using a 
simple formula. Subjects with higher difficulty and closer 
exam dates receive higher priority. 
Based on these priority scores and the total study hours 
available per day, the program recommends how much time 
should be allocated to each subject. 
AI Concept Used  
This project uses a basic recommendation technique inspired 
by AI decision-making. The system Analyses multiple factors 
and automatically suggests an optimized study plan, similar  
to how intelligent recommendation systems work. 
Features 
• User-friendly  
• Accepts multiple subjects as input. 
• Calculates subject priority automatically. 
• Recommends study hours for each subject. 
• Identifies the highest-priority subject. 
• Implements OOP concepts in Python. 
Conclusion 
The AI-Based Personal Study Planner is a practical and easy
to-use application that helps students prepare for exams more 
effectively. Although it uses a simple algorithm, it 
demonstrates the idea of intelligent decision-making and 
highlights how AI techniques can be applied to solve 
everyday problems.
